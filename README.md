# xyz-tui

Rust + Ratatui 小宇宙客户端，支持 macOS / Linux，已实现扫码登录、账号播放列表与音频播放。

播放需要 `mpv`。macOS 安装后启动：

```sh
brew install mpv
cargo run
```

用小宇宙 App 扫描终端二维码，在手机上确认。登录页用 `r` 刷新或重试，`Esc` 退出；`q` / `Ctrl+C` 在任意页面退出应用。

登录后显示居中的紧凑文字菜单：播放列表、订阅列表、推荐列表、设置。使用方向键、`j` / `k`、`Tab` / `Shift+Tab` 选择，或用 `1`–`4` 直接选中，按 `Enter` 进入对应详情页。详情页用 `Esc` / `Backspace` 返回菜单，并保留原先选择。进入设置后，按 `Enter` 执行文字按钮“退出登录”，返回扫码页。

进入播放列表会读取账号中的队列，按原顺序显示。每条单集占两行：上行为标题，下行用淡色显示“播客名 · 剩余时长”；选中时只突出标题。剩余时长按总时长减去云端收听进度计算，缺失进度时显示 `--:--`，进度请求失败时仍保留标题供浏览和重试。窄窗口会截短过长的播客名，保留剩余时长。当前接口不提供逐条加入时间，日期暂不显示。

`↑` / `↓` 或 `j` / `k` 选择，`PageUp` / `PageDown` 翻动，`Home` / `End` 或 `g` / `G` 到首尾，`r` 刷新或重试。`Enter` 播放选中单集并从云端进度续听，`x` 同时从小宇宙 App 的云端播放列表移除；服务器确认后才更新列表。移除正在播放的单集时，当前音频继续播放。返回菜单再进入会保留列表与选择。网络请求在后台完成，刷新失败时保留已有列表；单集读取失败保留其位置，可重试。

`Space` 在所有页面切换暂停 / 继续，底部两行显示当前单集和播放进度。浏览菜单、订阅、推荐或设置页不会打断播放。每 15 秒同步一次实际播放位置，暂停、换集、播放结束、退出时补发；网络失败时保留本次运行中的待同步进度，退避重试，429 遵循服务器指定间隔。退出会等待最后的同步，失败会明确报错；尚不支持断网退出后的进度恢复。已播放完的单集重新选择会从头播放。

订阅列表、推荐列表的内容尚未接入。登录后自动保存凭据，再次启动会校验已有登录；access token 过期时，用 refresh token 自动续期并保存新凭据。播放列表、媒体解析和进度请求共用登录状态，遇到 401 会自动续期，再重试一次，保留当前页面与选择。续期凭据被服务器判定失效时才需要重新扫码；网络故障或服务异常时保留凭据供重试。遇到限流需等待服务器指定的间隔后重试。

凭据存放在用户数据目录的 `xyz-tui/session.json`（macOS：`~/Library/Application Support/xyz-tui/session.json`；Linux：`${XDG_DATA_HOME:-~/.local/share}/xyz-tui/session.json`）。Unix 文件权限为 `0600`，原子写入。可用 `XYZ_TUI_STATE_DIR` 指定独立目录；删除该目录中的 `session.json` 可清除本地登录。同目录的 `device-id` 保存随机设备标识，供云端队列同步使用。凭据不会打印到终端或写入仓库，也不会传给 mpv 或音频 CDN。可以用 `XYZ_TUI_MPV` 指定 mpv 可执行文件路径。

```sh
cargo test
cargo clippy --all-targets -- -D warnings
# 安装 mpv 后执行真实解码测试（静音输出）
cargo test mpv_decodes -- --ignored
```
