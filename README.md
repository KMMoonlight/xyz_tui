# xyz-tui

Rust + Ratatui 小宇宙客户端，支持 macOS / Linux，已实现扫码登录、账号播放列表、订阅更新、实时榜单与推荐、收听时长与历史、单集详情与音频播放。

## Homebrew 安装与更新

macOS 14+、Apple Silicon 用户可以直接安装，无需另装 Rust。源码和安装包均已公开，安装无需 GitHub 登录或仓库授权：

```sh
brew install KMMoonlightQ/tools/xyz-tui
xyz
```

Homebrew 会自动安装播放依赖 `mpv`。安装后使用 `xyz` 启动，`xyz --version` 可查看版本，`xyz --help` 可查看启动说明；也保留 `xyz-tui` 作为兼容入口。

更新：

```sh
brew update
brew upgrade KMMoonlightQ/tools/xyz-tui
```

## 从源码运行

播放需要 `mpv`。macOS 安装后启动：

```sh
brew install mpv
cargo run
```

用小宇宙 App 扫描终端二维码，在手机上确认。登录页用 `r` 刷新或重试，`Esc` 退出；`q` / `Ctrl+C` 在任意页面退出应用。

登录完成后自动读取云端最近收听的单集及播放进度，仅填充暂停状态，播放区保持隐藏；按 `t` 查看，或按 `Space` 获取当前音频地址和最新进度、展开播放区并继续收听。恢复时不启动音频解码，也不会把暂停预览上报为新的收听记录。没有收听历史时保持空播放区，读取失败可按 `t` 查看错误、按 `Space` 重试；限流时遵循服务器指定的等待时间。启动期间手动选择其他单集会取消恢复，旧账号或旧请求不会覆盖当前播放。

各页面只在顶部右上角显示“？帮助”，按 `?`（`Shift+/`）弹出当前页面与全局快捷键列表，再按 `?`、`Esc` 或 `Backspace` 关闭。帮助内容可用方向键、`j` / `k`、`PageUp` / `PageDown` 滚动，`Home` / `End` 跳到首尾。帮助框打开时，页面操作暂时停用，`Space`、`a` / `d` 仍可控制播放，`t` 仍可切换播放区显示，`Shift+T` 可展开或还原已显示的播放区，`i` 可打开当前音频详情。

登录后显示居中的紧凑文字菜单：播放列表、订阅列表、推荐列表、设置。使用方向键、`j` / `k`、`Tab` / `Shift+Tab` 选择，或用 `1`–`4` 直接选中，按 `Enter` 进入对应详情页。详情页用 `Esc` / `Backspace` 返回菜单，并保留原先选择。进入设置后，按 `Tab` 选中“退出登录”，再按 `Enter` 返回扫码页。

进入播放列表会读取账号中的队列，按原顺序显示。每条单集占两行：上行为标题，下行用淡色显示“播客名 · 剩余时长”；选中时只突出标题。剩余时长按总时长减去云端收听进度计算，缺失进度时显示 `--:--`，进度请求失败时仍保留标题供浏览和重试。窄窗口会截短过长的播客名，保留剩余时长。当前接口不提供逐条加入时间，日期暂不显示。

`↑` / `↓` 或 `j` / `k` 选择，`PageUp` / `PageDown` 翻动，`Home` / `End` 或 `g` / `G` 到首尾，`r` 刷新或重试。`Enter` 播放选中单集并从云端进度续听，同时将该单集移到云端播放列表首位，`x` 同时从小宇宙 App 的云端播放列表移除；服务器确认后才更新列表。移除当前播放或暂停的单集时，确认成功后立即停止该音频、保存实际收听进度，并按队列顺序播放下一集；没有下一集时停止播放。移除失败或移除其他单集时，当前播放不受影响。返回菜单再进入会保留列表与选择。网络请求在后台完成，刷新失败时保留已有列表；单集读取失败保留其位置，可重试。

`Space` 在所有页面切换暂停 / 继续，`a` 后退 15 秒，`d` 快进 15 秒；暂停时也可跳转，并保持暂停。底部播放区以浮层覆盖页面，不改变列表或详情页的布局；字幕区增高，并通过内部横线与音频信息区分开，时间前以 `#` 显示播放进度。`t` 显示 / 隐藏播放区，隐藏不影响播放，手动播放新单集或自动续播下一集时默认展开；播放区显示时，按 `Shift+T` 铺满主内容区域（保留顶部帮助入口），字幕随之扩展；再次按 `Shift+T` 或 `Esc` / `Backspace` 还原底部浮层。全区域模式下，页面列表操作暂时停用，`Space`、`a` / `d` 和帮助仍可使用；按 `t` 隐藏后再次显示会回到普通高度。播放区隐藏或无内容时，`Shift+T` 不生效。播放区显示时，按 `i` 打开当前音频的“详情 / 评论”页面，同时收起播放区；音频继续播放，按 `Esc` 返回原页面并保留列表选择和原详情状态。普通与全区域播放区均支持该操作，播放区隐藏或没有当前音频时不生效。帮助框显示在播放区上方。浏览菜单、订阅、推荐或设置页不会打断播放。每 15 秒同步一次实际播放位置，暂停、换集、播放结束、退出时补发；网络失败时保留本次运行中的待同步进度，退避重试，429 遵循服务器指定间隔。退出会等待最后的同步，失败会明确报错；尚不支持断网退出后的进度恢复。已播放完的单集重新选择会从头播放。

单集正常播完后，会自动从云端播放列表移除（服务器确认后更新列表），并按队列顺序播放下一集、从其收听进度续播；续播不受当前页面或光标选择影响。播放到队尾时停止，播放失败时保留单集供重试。自动移除失败会显示提示并保留列表项，可用 `x` 重试，不影响下一集播放。

有逐字稿的单集会在播放或恢复最近收听时自动加载字幕：底部高亮当前句，淡色显示前后句，按实际换行高度紧接排列，余下空间展示后续字幕；字幕与音频信息之间只显示横线。字幕随播放、`a` / `d` 跳转同步更新，暂停时保留当前字幕。没有逐字稿时保持原布局，不显示提示或占位。字幕在后台加载，暂时获取失败会重试，不打断音频；小窗口优先保留播放控制，字幕自动隐藏。

进入订阅列表会按服务端顺序展示已订阅播客的单集更新。每条占两行：第一行显示音频标题，第二行左侧显示播客名称，右侧显示“总时长 · 发布时间”，播客名过长时截短以保留时长和日期；`↑` / `↓` 或 `j` / `k` 选择，`PageUp` / `PageDown`、`←` / `→` 或 `p` / `n` 翻页，`Home` / `End` 或 `g` / `G` 到当前页首尾。分页大小由服务器决定，已读页面及选择会缓存；`r` 刷新，翻页失败时 `r` 重试失败页，保留已有内容。

订阅列表按 `Enter` 打开单集详情：顶部使用与推荐列表一致的“详情 / 评论”标签，选中项以青色加粗和下划线突出，按 `Tab` / `Shift+Tab` 切换。标签下固定显示两行单集信息：标题，以及左侧播客名称、右侧总时长和发布时间。默认打开“详情”，用完整内容区域渲染 Markdown / HTML 简介；切到“评论”后，用同一区域显示按热度分页的用户主评论。评论仅供阅读，用户名以青色加粗显示。两个标签各自保留滚动位置；`↑` / `↓`、`j` / `k`、`PageUp` / `PageDown` 滚动，`Home` / `End` 到当前标签首尾。评论标签内用 `n` / `p` 或左右方向键翻页，`r` 刷新或重试当前标签。`Esc` / `Backspace` 返回订阅列表并保留位置。在详情页再次按 `Enter` 直接播放并续听，同时自动加入云端播放列表首位；已有单集移到首位且不重复，加入失败可按 `y` 重试，不中断播放。

订阅、推荐、收听历史列表和详情页均可按 `y` 将选中单集加入小宇宙云端播放列表首位；已有单集移到首位，其他单集保持相对顺序。服务器确认并读回后显示成功提示、刷新播放列表，失败显示错误供重试。加入操作不会切换当前音频，全局播放快捷键继续可用。

推荐列表包含最热榜、锋芒榜、新星榜、编辑推荐和为你推荐。进入时读取当前完整最热榜，按 `Tab` / `Shift+Tab` 或 `1`–`5` 切换分类，分类首次打开时加载，各自保留页面和选择；`r` 获取最新内容或重试失败页。三份榜单按服务端排名显示序号；编辑推荐按日期从新到旧展示，可翻页阅读往日精选；为你推荐读取发现页中的单集推荐，跳过横幅和仅含播客合集的模块。列表沿用订阅列表的两行布局、选择和翻页操作，按 `Enter` 打开同一个单集详情页，支持简介、只读评论、播放续听和 `y` 加入播放列表；`Esc` 返回原分类并保留位置。详情页中的 `Tab` 切换“详情 / 评论”标签。

设置页顶部展示账号的累计收听时长（小时、分钟），下方按服务端顺序展示收听历史。历史沿用订阅、推荐列表的两行布局：标题在上，淡色播客名、单集时长与发布日期在下，仅高亮选中标题；分页、首尾选择、详情、评论、续听及 `y` 加入播放列表的操作相同。`r` 刷新时长和历史，加载或刷新失败时保留已有数据，限流后按提示等待重试。返回再进入保留页码和选择，播放后的云端变化可按 `r` 获取。`Tab` / `Shift+Tab` 在历史列表和退出登录间切换，选中退出登录后按 `Enter` 执行；单集详情中的 `Tab` 仍用于切换详情 / 评论。累计时长直接读取云端统计，不将单集总时长或播放位置相加；显示值以服务器统计为准。

登录后自动保存凭据，再次启动会校验已有登录；access token 过期时，用 refresh token 自动续期并保存新凭据。播放列表、订阅、推荐、收听统计与历史、详情、评论、媒体解析和进度请求共用登录状态，遇到 401 会自动续期，再重试一次，保留当前页面与选择。续期凭据被服务器判定失效时才需要重新扫码；网络故障或服务异常时保留凭据供重试。遇到限流需等待服务器指定的间隔后重试。

凭据存放在用户数据目录的 `xyz-tui/session.json`（macOS：`~/Library/Application Support/xyz-tui/session.json`；Linux：`${XDG_DATA_HOME:-~/.local/share}/xyz-tui/session.json`）。Unix 文件权限为 `0600`，原子写入。可用 `XYZ_TUI_STATE_DIR` 指定独立目录；删除该目录中的 `session.json` 可清除本地登录。同目录的 `device-id` 保存随机设备标识，供云端队列同步使用。凭据不会打印到终端或写入仓库，也不会传给 mpv 或音频 CDN。可以用 `XYZ_TUI_MPV` 指定 mpv 可执行文件路径。

```sh
cargo test
cargo clippy --all-targets -- -D warnings
# 安装 mpv 后执行真实解码测试（静音输出）
cargo test mpv_decodes -- --ignored
```
